# P0+P1 架构重构执行计划

> 本计划取代原第三轮审查计划中的兼容层和空扩展字段方案。

## 目标

把 `AppRuntime` 从数据容器升级为运行时入口，减少 `cli_app` 的总装职责，为后续插件贡献工具、MCP、hook 留出真实入口。

执行原则：

- 不保留 `cli_app/factories.py` 兼容层。
- 不提前给 `PluginManifest` 加 `tools/hooks/mcp_servers` 空字段。
- 只实现当前能被代码路径和测试验证的扩展点。
- 插件 manifest 扩展等到加载逻辑一起实现。

## 已接受项

- [x] `ReplRouter` 不再接收 `build_agent/run_agent_once/list_tools/chat_fn/build_branch_summary` 这 5 个函数参数。
- [x] `ReplRouter` 通过 `AppRuntime` 获取 agent 构建、单轮执行、工具列表、LLM 调用、分支摘要能力。
- [x] `runner.py` 不再组装默认工具，不再自己加载 MCP tools。
- [x] `AppRuntime` 持有 `chat_fn` 和 `mcp_manager`。
- [x] `AppRuntime.create()` 可在未传 `tool_runtime` 时创建默认工具运行时。
- [x] `AppRuntime.load_mcp_tools()` 负责启动 MCP server 并注册 MCP tool wrapper。
- [x] `AppRuntime.shutdown()` 负责关闭 MCP manager。
- [x] 默认工具构建迁到 `tooling/defaults.py`。
- [x] 单轮 agent 执行核心迁到 `app_runtime/agent_execution.py`。
- [x] 长期记忆构造迁到 `memory.build_long_term_memory()`。
- [x] `cli_app/factories.py` 删除，不留 deprecated wrapper。
- [x] `tooling.__all__` 不再导出 `FileTracker/ReadStateCache/register_freshness_guard` 等内部机制。

## 明确拒绝项

- [x] 不创建 `app_runtime/builders.py` 大杂烩。

  默认工具属于 `tooling`，长期记忆属于 `memory`，agent 执行属于 `app_runtime`。硬塞进 builders 会再次制造“总装疙瘩”。

- [x] 不把 `cli_app/factories.py` 改成兼容层。

  当前项目不是生产 SDK，升级应直接删除旧入口，避免测试和新代码继续依赖旧结构。

- [x] 不给 `PluginManifest` 提前加 `tools/hooks/mcp_servers` 字段。

  这些字段如果没有加载、校验、生命周期管理和测试，只是空 API。后续真正实现插件贡献工具、MCP、hook 时再加。

- [x] 不把 MCP 加载塞进 `AppRuntime.create()`。

  MCP 启动可能拉进外部进程和网络依赖。`create()` 保持轻量，`load_mcp_tools()` 作为显式生命周期步骤，更适合测试和后续插件接入。

## 文件落点

- `tooling/defaults.py`
  - `build_default_tool_runtime()`
  - `format_tool_list()`

- `app_runtime/agent_execution.py`
  - `run_agent_once()`
  - `/plan` 单 agent 执行语义
  - agent event 渲染和错误处理

- `app_runtime/runtime.py`
  - `build_agent()`
  - `run_agent_once()`
  - `list_tools()`
  - `chat()`
  - `build_branch_summary()`
  - `load_mcp_tools()`
  - `shutdown()`

- `memory/long_term.py`
  - `DEFAULT_LONG_TERM_PATH`
  - `build_long_term_memory()`

- `cli_app/runner.py`
  - 只负责 dotenv、创建 `AppRuntime`、加载 MCP、创建 `ReplRouter`、终端输入循环。

- `cli_app/router.py`
  - 只接收 `app_runtime`、`renderer`、少量交互选项。

## 验收标准

- [x] `cli_app/factories.py` 不存在。
- [x] `ReplRouter.__init__` 不包含 5 个函数注入参数。
- [x] `runner.py` 不导入默认工具构建函数和 agent factory。
- [x] MCP tool 加载由 `AppRuntime.load_mcp_tools()` 负责。
- [x] `tooling.__all__` 不导出内部缓存和 freshness guard。
- [x] `PluginManifest` 不包含未实现的 `tools/hooks/mcp_servers` 空字段。
- [x] 全量测试通过：`python -m unittest discover -s tests -v`。
